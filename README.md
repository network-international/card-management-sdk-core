# NI Card Management SDK — Core (public binaries)

Public binary distribution for Network International Card Management SDK **Core**.

| Artifact | Location |
| --- | --- |
| iOS XCFramework | GitHub Releases + SPM `Package.swift` (this repo) |
| Android AAR | Maven Central `ae.network:ni-card-management-sdk-core` |

Source code is **private** (Bitbucket). Debug symbols are provided by Network International support on request for a specific Core version.

See [PUBLIC_BINARIES.md](./PUBLIC_BINARIES.md) and [Releases](https://github.com/network-international/card-management-sdk-core/releases).
